# Expanded adaptive-panel replacement pilot (v2.6)

## Decision

Do not replace the current biology-guided 10-gene panel with the discovery-only 28-gene adaptive panel.

## Evidence

- Chen held-out AUC: adaptive 0.917, 100-gene reference 0.929, compact 10-gene 0.936.
- External platform evaluability: adaptive 1/5 cohorts, 100-gene reference 5/5, compact 10-gene 5/5 (80% required in each arm).
- Five-cohort pooled standardized adenoma effect: reference 1.925 (95% CI 1.770–2.079); compact 10-gene 1.906 (1.755–2.057). The adaptive panel was not pooled because only one cohort was evaluable.
- FFPE paired positive fraction: adaptive 0.961; reference 0.961; compact 10-gene 0.961 (51 pairs).
- The adaptive panel's portability loss is mechanistically traceable to multiple LINC/LNC and annotation-sensitive genes absent from older array platforms; its down arm also provides weaker mature-epithelial interpretability.

## Recommended manuscript treatment

1. Define the biological programme by the complete 287-gene error-controlled core (BH FDR plus donor-bootstrap direction stability and confidence interval), avoiding a fixed-count claim at the discovery layer.
2. Retain the 100-gene score as an established balanced research implementation and sensitivity reference, not as the biological definition of the programme.
3. Retain and deepen the 10-gene panel as the closing compact candidate because it is fully measurable in all five external cohorts and FFPE, preserves the external effect, and retains explicit WNT/stem and mature-differentiation anchors.
4. Keep the 28-gene adaptive exercise as an internal selection audit or, at most, a supplementary robustness analysis; it should not replace the manuscript panel.

No v2.5 manuscript, main figure, table or supplementary file was overwritten by this pilot.
